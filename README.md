## 🎮 How to Play

QuizQuest has **4 different modes**. Choose the mode based on how you want to conduct the quiz.

---

# 👥 1. Team Game — Multi-Device

### 🎯 Why use this mode?

Use **Team Game** when students are divided into teams and each student uses their **own phone, laptop, or device**.

The mentor controls the game, while students join their team using a game code.

### 🧑‍🏫 Mentor Side

1. Open the **Mentor Login**.
2. Login to the **Mentor Dashboard**.
3. Open **Sessions**.
4. Click **👥 Team Session**.
5. Enter a **Session Title**.
6. Select the **Difficulty**:
   - 🎯 All Levels
   - 🟢 Easy
   - 🟡 Medium
   - 🔴 Hard
7. Select the **Topics** you want to use.
8. Select the **number of teams**.
9. Customize each team's:
   - Name
   - Emoji
   - Color
10. Select **Questions Per Team**.
11. Set the **Timer**.
12. Click **🚀 Create & Get Code**.
13. Share the generated **6-character game code** with the students.
14. Wait for students to join.
15. Open **Live Control**.
16. Check the students and teams.
17. Click **🚀 Start Game**.

### 👨‍🎓 Student Side

1. Open the **QuizQuest website**.
2. Select **📱 Team Game**.
3. Enter your **nickname**.
4. Enter the **game code** given by the mentor.
5. Select an **avatar**.
6. Click **Continue**.
7. Select your **team**.
8. Click **Join Team**.
9. Wait in the lobby until the mentor starts the game.

### 🎯 During the Game

1. The current team gets a turn.
2. The team chooses a **topic**.
3. A question appears.
4. The team answers before the timer ends.
5. Correct answer → **points are added**.
6. Wrong answer → **points are deducted**.
7. The next team gets its turn.
8. The starting team rotates after every round.
9. Continue until all rounds are completed.
10. The final **leaderboard** shows the winning team.

### ⭐ Special Features

- 🎯 **50/50 Lifeline** — removes incorrect options.
- 🔥 **Streak Bonus** — consecutive correct answers can increase the score multiplier.
- ⚡ **Double Points** — the mentor can activate 2× points for the next question.
- 🎯 **Comeback Bonus** — the team in last place can receive an extra **125 points** for a correct answer during the final 3 rounds.
- ⚡ **Speed Bonus** — answering correctly with more time remaining gives extra points.

# 🏅 2. Solo Player — Individual Mode

### 🎯 Why use this mode?

Use **Solo Player** when students should compete **individually instead of being divided into teams**.

Each student has their own score and appears separately on the live leaderboard.

### 🧑‍🏫 Mentor Side

1. Open the **Mentor Dashboard**.
2. Go to **Sessions**.
3. Click **🏅 Solo Session**.
4. Enter a **Session Title**.
5. Select the **Difficulty**.
6. Select the **Topics**.
7. Set **Questions Per Round**.
8. Set the **Timer**.
9. Set the **Maximum Number of Players**.
10. Click **🏅 Create Solo Session & Get Code**.
11. Share the generated **game code** with all students.
12. Open **Live Control**.
13. Wait for students to join.
14. Check the live player list.
15. Click **🚀 Start Game**.

### 👨‍🎓 Student Side

1. Open the **QuizQuest website**.
2. Select **🏅 Solo Player**.
3. Enter your **name**.
4. Enter the **game code** from the mentor.
5. Select an **avatar**.
6. Click **🏅 Enter Solo Game**.
7. Wait for the mentor to start the game.

### 🎯 During the Game

1. All students receive the question.
2. Every student answers individually.
3. Students have the same timer.
4. After everyone answers, the correct answer and scores are shown.
5. The leaderboard updates with each student's score.
6. The game continues until all questions are completed.
7. The final leaderboard shows the ranking of all students.

### ⭐ Special Features

- 🏅 Individual scoring
- 📊 Live student leaderboard
- 🎯 50/50 Lifeline
- ⚡ Speed Bonus
- 🎯 Comeback Bonus for the lowest-scoring player during the final rounds

# 🖥️ 3. Shared Screen Mode — Single Device

### 🎯 Why use this mode?

Use **Shared Screen Mode** when everyone is together in one place and you want to play the quiz on **one laptop, computer, TV, or projector**.

**No phones are required.**

This mode runs directly on the shared screen.

### 🧑‍🏫 How to Start

1. Open the **QuizQuest website**.
2. Select **🖥️ Shared Screen**.
3. Select the **number of teams**.
4. Select **Questions Per Team**.
5. Set the **Timer**.
6. Customize the **team names**.
7. Click **🚀 Start Shared Game**.

### 🎯 During the Game

1. The screen shows which team's turn it is.
2. The team chooses a **topic**.
3. The mentor chooses the **difficulty**:
   - 🟢 Easy
   - 🟡 Medium
   - 🔴 Hard
4. The question appears on the shared screen.
5. The team discusses the answer.
6. Select the answer on the shared screen.
7. The result is shown immediately.
8. The score is updated.
9. The next team gets its turn.
10. Continue until all rounds are completed.
11. The final screen shows the winning team.

### ⭐ Special Features

- 🎯 50/50 Lifeline
- ⚡ Speed Bonus
- 🎯 Comeback Bonus
- ⏱️ Timer
- 🏆 Final leaderboard
- 🔊 Correct and wrong answer sounds

# 🎯 4. Practice Mode — Learn and Practice

### 🎯 Why use this mode?

Use **Practice Mode** when a student wants to practice alone without joining a live game.

There is:

- ❌ No game code
- ❌ No mentor
- ❌ No team
- ❌ No time pressure

### 👨‍🎓 How to Practice

1. Open the **QuizQuest website**.
2. Select **🎯 Practice Mode**.
3. Choose a **topic**.
4. Start the practice questions.
5. Read the question and options.
6. Select an answer.
7. The correct answer is shown immediately.
8. Read the explanation.
9. Continue to the next question.
10. Complete the practice session.
11. View your final score.

### ⭐ Practice Features

- 📚 Topic-based practice
- ⏱️ No time limit
- ✅ Instant answer feedback
- 💡 Explanations
- 🔊 Read-aloud support
- ⭐ Earn stars
- 🔥 Track your streak
- 🏆 Practice result and score

# ⚡ Scoring

### Difficulty Points

| Difficulty | Correct | Wrong |
|---|---:|---:|
| 🟢 **Easy** | +100 | −50 |
| 🟡 **Medium** | +150 | −75 |
| 🔴 **Hard** | +200 | −100 |

### Additional Bonuses

- ⚡ **Speed Bonus:** Extra points for answering correctly before the timer runs out.
- 🔥 **Streak Bonus:** Consecutive correct answers can increase the score multiplier.
- ⚡ **Double Points:** Mentor can make the next question worth **2× points**.
- 🎯 **Comeback Bonus:** The player/team in last place can receive **+125 points** for a correct answer during the final 3 rounds.
- 🎯 **50/50 Lifeline:** Removes incorrect answer options. Each team/player has a limited number of uses.

---

# 🏁 After the Game

When all questions are completed:

1. The game ends.
2. Final scores are calculated.
3. The leaderboard is displayed.
4. 🥇 1st place
5. 🥈 2nd place
6. 🥉 3rd place
7. The remaining players/teams are shown in ranking order.
