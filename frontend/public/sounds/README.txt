QuizQuest sound effects
========================
Drop three MP3 files right here (same folder as this README), using these
EXACT filenames — the app already looks for them at these paths:

  correct.mp3   → plays when a player/team answers correctly
  wrong.mp3     → plays when a player/team answers wrong or times out
  winner.mp3    → plays once when the final leaderboard appears

Until you add these files, the game runs completely normally — it just
plays no sound (the code fails silently if a file is missing).

RECOMMENDED FREE SOURCES (no login, no attribution required):
  Pixabay  — https://pixabay.com/sound-effects/search/winner%20celebration/
             https://pixabay.com/sound-effects/search/wrong%20answer/
             (click a sound → Download → choose "MP3")
  Mixkit   — https://mixkit.co/free-sound-effects/win/
             https://mixkit.co/free-sound-effects/wrong/
             (free for commercial use, no attribution required)

Pick short, punchy, kid-friendly ones (1-3 seconds for correct/wrong,
up to ~5 seconds for the winner fanfare) so they don't slow the game down.
